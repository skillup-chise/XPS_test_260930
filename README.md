# XPS データ自動解析 Web アプリ

Python と Streamlit で動作する、X線光電子分光（XPS）スペクトルの自動解析ツールです。  
CSV / TXT の測定データをブラウザ上で読み込み、背景補正・ピーク検出・軌道アサイン・ガウス–ローレンツ複合フィッティング・インタラクティブ可視化までを一連で行えます。

## 主な機能

1. **ファイル読み込み** — Binding Energy / Intensity の CSV、または Excel（.xlsx / .xls）をアップロード（Excel はシート・列を選択可能）
2. **背景補正** — Shirley 法または直線近似によるベースライン引算
3. **ピーク自動検出 & 元素推定** — `scipy.signal.find_peaks` と代表結合エネルギーテーブルによる軌道候補アサイン
4. **ピークフィッティング** — `lmfit` の PseudoVoigt（ガウス・ローレンツ複合）による複数ピーク分離、位置・FWHM・面積強度の算出
5. **インタラクティブ描画** — Plotly で元データ・背景・各軌道ピーク（色分け）・合成フィットを重ね表示

### 配色ルール（色覚バリアフリー）

- **Okabe-Ito パレット**（`#E69F00`, `#56B4E9`, `#009E73`, `#F0E442`, `#0072B2`, `#D55E00`, `#CC79A7` など）を使用し、赤緑の混同を避けます
- **`ORBITAL_COLORS` 辞書**で「C 1s」「O 1s」などの軌道名と色を 1 対 1 対応させ、同じ軌道は常に同じ色で表示します

## ローカルでの実行手順

### 1. 依存関係のインストール

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. アプリの起動

```bash
streamlit run app.py
```

ブラウザが開き、サイドバーからファイルアップロードや解析パラメータを操作できます。  
ファイルを指定しない場合は、C 1s / N 1s / O 1s 付近のサンプルスペクトルで動作確認できます。

## Streamlit Community Cloud へのデプロイ

1. 本リポジトリを GitHub にプッシュする
2. [Streamlit Community Cloud](https://share.streamlit.io/) にログインし **New app** を選択
3. リポジトリ・ブランチ・Main file path に `app.py` を指定してデプロイ
4. `requirements.txt` が自動認識され、依存パッケージがインストールされます

## 入力データの形式

### CSV

| 列 | 内容 | 例 |
|----|------|----|
| 1列目 | Binding Energy (eV) | 295.0, 294.9, … |
| 2列目 | Intensity | 1200, 1185, … |

- 区切りはカンマ・タブ・空白のいずれかに対応
- ヘッダー行の有無は自動判定

### Excel（.xlsx / .xls）

- 複数シートがある場合は画面上のセレクトボックスでシートを選択
- 読み込み後にプレビューを表示し、X軸（結合エネルギー）と Y軸（強度）の列をそれぞれ選択
- 選択列は数値化・欠損除去のうえ解析パイプラインへ渡されます

XPS 慣例に合わせ、グラフ横軸は結合エネルギーを右→左（高→低）で表示します

## 解析の流れ（アルゴリズム概要）

1. データを読み込み、必要に応じて Savitzky-Golay 平滑化
2. Shirley または直線近似で背景を推定し、スペクトルから差し引く
3. `find_peaks` でピーク位置を検出し、参照 BE テーブルで軌道候補をアサイン
4. 各ピークを PseudoVoigt モデルで同時フィットし、位置・FWHM・面積を算出
5. Plotly で結果をインタラクティブに可視化（軌道色は `ORBITAL_COLORS` で固定）
